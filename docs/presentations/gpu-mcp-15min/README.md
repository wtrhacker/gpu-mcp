# GPU MCP presentation

Presentation files:

- `GPU_MCP_for_Polymer_Simulators.pdf` — twelve-slide deck for presenting
  or sharing.
- `GPU_MCP_for_Polymer_Simulators.html` — browser presentation; use arrow
  keys, Page Up/Down, or Space to navigate.
- `speaker_notes.md` — talk track plus an optional safe demo prompt.
- `slides/` — rendered PNG slides used by the browser deck.

Rebuild after editing `generate_deck.py`:

```bash
MPLCONFIGDIR=/tmp/gpu_mcp_slide_matplotlib python generate_deck.py
```
